# Volet C — Data Scientist

## Objectif du volet

Ce dossier contient le travail réalisé pour le volet C Data Scientist du projet Néovolt Grid+.

Le cas d’usage retenu est la prévision de consommation électrique quotidienne.

L’objectif est de construire un prototype de modèle permettant d’anticiper la consommation totale journalière à partir :
- de l’historique de consommation ;
- des variables calendaires ;
- des données météorologiques ;
- des indicateurs de saisonnalité.

Le modèle doit aider Néovolt à mieux anticiper les pics de demande, préparer les achats d’énergie et améliorer la stabilité du réseau.


Cas d’usage : prévision de consommation.
