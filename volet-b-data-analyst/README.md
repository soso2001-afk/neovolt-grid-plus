# Volet B — Data Analyst

Nettoyage, analyses, dashboards, rapport métier.
## Objectif du volet

Ce dossier contient le travail réalisé pour le volet B Data Analyst du projet Néovolt Grid+.

L’objectif est de transformer les données de consommation et les données associées en analyses exploitables par les décideurs de Néovolt : exploitation réseau, direction financière et relation client.

Le travail couvre :
- l’exploration et la qualité des données ;
- le nettoyage et la préparation des données ;
- l’analyse descriptive et multivariée ;
- l’analyse temporelle et météo ;
- la préparation des données pour un tableau de bord Power BI ;
- la restitution des résultats sous forme de recommandations métier.

## Outils utilisés

- Python
- Jupyter Notebook
- pandas
- numpy
- matplotlib
- plotly
- Power BI Desktop
- GitHub
